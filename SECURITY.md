# Security

This repository is a prototype for an encrypted, untrusted public submission intake —
not accepting real reports yet. Do not commit private data, credentials, real vehicle
plates, reporter details or downloaded user files. No outbound network code is included.
Report vulnerabilities through this repository's private vulnerability reporting form:
https://github.com/reihlinstinct/parking-report-intake/security/advisories/new
Hebrew or English. No personal email is published on purpose. This repo serves no website,
so there is no security.txt here; the sibling project publishes one
(https://github.com/reihlinstinct/ginot-hair-plans/blob/main/docs/.well-known/security.txt). Do not include secrets in public issues.
